# Outreach — Real Validation Conversations Only

**Rule, non-negotiable (`CLAUDE.md` rule 5):** never cite a synthetic or
AI-roleplayed user as validation evidence here. An LLM playing a merchant
agrees with whatever it's handed — no ground truth, and citing "synthetic
interview" to a judge is a credibility kill shot. Personas may only be used
elsewhere, privately, to rehearse a pitch before taking it to a real person —
never logged in this folder, never in `submission/`.

Target: 3–5 real conversations on Day 4, begun early — five real
conversations started on Day 4 beat ten rushed ones on Day 13. The goal is
the moment someone says "actually the real problem is X," not a headcount.

## Log format

One file per conversation: `NN-role-or-context.md` (e.g.
`01-d2c-merchant-founder.md`). Capture: who they are (role, not name, unless
they've okayed attribution), what they said unprompted, what surprised you,
and whether it changed the problem thesis. If it did, that's a decision —
write the ADR.
