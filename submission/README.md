# Submission

Everything in this folder is a deliverable that eventually reaches Razorpay —
a judge, a reviewer, or the founder contact. Nothing here is scratch work.

- **`one-pagers/`** — one page per surviving candidate problem, written Day 3
  (Gate 1). If you can't write the one-pager, you don't understand the
  problem yet — that's the test.
- **`demo-script.md`** — written Day 5, *before any code*, right after the
  problem lock. If you can't script 90 compelling seconds, the project is
  wrong and Day 5 is a cheap day to learn that.
- **`narrative.md`** — the final submission writeup, Day 15: problem →
  evidence → insight → system → results → why Razorpay should care → what's
  next.
- **`founder-email.md`** — drafted whenever, **sent never** until the project
  thesis is locked. See `CLAUDE.md` rule 8. Direct founder access is
  high-value; don't burn it on an unfinished thesis.

Rule from `CLAUDE.md`: no feature exists in `src/` that isn't in
`demo-script.md`. If it's not on screen for 90 seconds, it isn't earning its
build time.
